Passo a passo — tratamento dos dados do Qualinet no Extrator de Visitas Técnicas

Objetivo: orientar a extração, preparação, processamento, conferência e geração da planilha diária de Visitas Técnicas usando os dados consultados no Qualinet.

O Qualinet é um sistema utilizado para o acompanhamento de solicitações técnicas presenciais, incluindo agendamentos de visitas técnicas, recorrências e demandas regulatórias. Ele é uma ferramenta importante para consulta, monitoramento e análise das Ordens de Serviço, permitindo que o usuário acompanhe informações relacionadas aos atendimentos técnicos realizados em campo.

Para acessar o sistema, o usuário deve inicialmente realizar o login utilizando seu login corporativo e a senha corporativa. Após essa primeira etapa, é necessário concluir a autenticação por duplo fator, utilizando o código gerado pelo sistema de segurança da Claro (Duplo Fator), conhecido como Claro-2FA. Esse processo garante maior segurança no acesso às informações operacionais.

Depois da autenticação, o usuário deve selecionar o aplicativo Qualinet na lista de aplicativos disponíveis. Em seguida, o sistema realiza o download ou abertura via Citrix, permitindo o acesso ao ambiente do Qualinet. Após a abertura da nova janela, é necessário efetuar novamente o login com as credenciais corporativas para entrar no domínio e acessar as funcionalidades do sistema.

Dentro do Qualinet, uma das principais opções utilizadas é o Monitor de Ordem de Serviço. Essa funcionalidade permite consultar, acompanhar e filtrar Ordens de Serviço relacionadas às visitas técnicas. Nessa tela, é possível visualizar informações como cidade, tipo de serviço, agenda inicial e final, regional, segmento, node, GPON, endereço, abertura da solicitação, prazo Qualinet/Anatel e observações registradas sobre o atendimento.

A consulta pode ser feita por meio de filtros específicos, permitindo ao usuário segmentar os dados conforme a necessidade operacional. Entre os filtros apresentados no material estão informações como Tipo de Serviços, Cidade, Regional, Garantia do Serviço, Segmento, Região, além da possibilidade de separar a visualização por cidade. Essa organização facilita a análise das visitas técnicas, principalmente quando há grande volume de Ordens de Serviço em aberto ou agendadas.

Vamos apresentar um exemplo de consulta voltada para a região SP Leste, na qual as cidades são separadas por DDD. Para o DDD 12, são consideradas cidades como Aparecida, Caçapava, Cachoeira Paulista, Campos do Jordão, Caraguatatuba, Cruzeiro, Guaratinguetá, Jacareí, Lorena, Pindamonhangaba, Potim, São José dos Campos, São Sebastião, Taubaté, Tremembé e Ubatuba. Já para o DDD 13, são listadas cidades como Bertioga, Cubatão, Guarujá, Itanhaém, Mongaguá, Peruíbe, Praia Grande, Registro, Santos, São Vicente.

No campo Tipo de Serviços, configurar a consulta ex: RETRN CREDENC, S SINAL DIG, S SINAL NTF, S SINAL PTV, S SINAL VTA, VT DIG, VT NOW, VT VOIP, VT VTA. Esses tipos de serviço são importantes para delimitar corretamente o universo de visitas técnicas que serão analisadas, garantindo que a consulta retorne apenas os registros relevantes para o acompanhamento operacional.

Para coletar os dados do Qualinet selecione todo o conteúdo (Dica: usar Ctrl+A). Muita atenção para não colar dados em duplicidade. Salve em um arquivo .txt para inserir em Anexar o arquivo .txt ou copie e cole na caixa de inserção de dados correspondente.

Processar no HTML: clique em PROCESSAR DADOS QUALINET.

Dessa forma, o Qualinet funciona como uma ferramenta essencial para o controle e acompanhamento das visitas técnicas, permitindo identificar a situação das Ordens de Serviço, verificar prazos, analisar sintomas reportados pelos clientes, acompanhar recorrências e organizar os atendimentos por cidade, DDD, regional ou tipo de serviço. O uso correto dos filtros e das informações disponíveis no sistema contribui para uma análise mais precisa, facilitando a tomada de decisão e o direcionamento das ações operacionais.

Gerar a planilha: clique em GERAR PLANILHA DE VISITAS, escolha a aba/hora de destino 8 (08:00), 11 (11:00), 14 (14:00), 17 (17:00) ou 20 (20:00) e siga a condição apresentada pelo sistema para salvar novo arquivo ou atualizar arquivo existente.

Conferir a prévia: após gerar o Excel, use a seleção Visualização do print gerado para conferir Principal, MENU ou uma aba específica.

Copiar ou imprimir: use Copiar Print para copiar a prévia como imagem ou baixar PNG caso o navegador bloqueie a área de transferência. Use Imprimir prévia quando precisar registrar o relatório.

Passo a passo — tratamento dos dados do Qualinet no Extrator de Visitas Técnicas

Objetivo: orientar a extração, preparação, processamento, conferência e geração da planilha diária de Visitas Técnicas SP LESTE usando os dados consultados no Qualinet.

  1. Acessar o Qualinet: entre no ambiente corporativo com login e senha, realize a autenticação de duplo fator e abra o item Qualinet/Citrix conforme o procedimento interno.
  2. Abrir o Monitor de Ordem de Serviço: dentro do Qualinet, selecione a opção Monitor de Ordem de Serviço para iniciar a consulta das visitas técnicas.
  3. Configurar a consulta: na seleção de itens, filtre os tipos de serviço usados na rotina SP LESTE: RETRN CREDENC, S SINAL DIG, S SINAL NTF, S SINAL PTV, S SINAL VTA, VT DIG, VT NOW, VT VOIP e VT VTA.
  4. Separar a consulta por DDD: consulte separadamente as cidades do DDD12 e depois as cidades do DDD13, evitando misturar os blocos de dados.
  5. Copiar os dados do Qualinet: após a consulta, selecione/copiar o resultado referente ao DDD consultado, mantendo as linhas com cidade, tipo de serviço, data/hora de abertura quando disponível e demais informações retornadas pelo sistema.
  6. Processar no HTML: clique em PROCESSAR DADOS QUALINET, cole o conteúdo do DDD12 na aba DDD12 e o conteúdo do DDD13 na aba DDD13. As duas abas devem estar preenchidas e não podem conter exatamente o mesmo texto.
  7. Validar segmentações: use os filtros laterais de Data de abertura, Horário HH:00, DDD, Cidade e Serviço para conferir se os totais, gráficos e tabela compacta refletem corretamente a consulta.
  8. Gerar a planilha: clique em GERAR PLANILHA DE VISITAS, escolha a aba/hora de destino 8, 11, 14, 17 ou 20 e siga a condição apresentada pelo sistema para salvar novo arquivo ou atualizar arquivo existente.
  9. Conferir a prévia: após gerar o Excel, use a seleção Visualização do print gerado para conferir Principal, MENU ou uma aba específica. No MENU, valor zero aparece verde e célula vazia permanece branca.
  10. Copiar ou imprimir: use Copiar Print para copiar a prévia como imagem ou baixar PNG caso o navegador bloqueie a área de transferência. Use Imprimir prévia quando precisar registrar o relatório.
  11. Conferência final: antes de compartilhar, confirme se a aba 17 está com apenas uma coluna DIGITAL e apenas uma coluna TOTAL, seguindo o mesmo padrão das abas 8, 11, 14 e 20.
